# 私人菜谱小程序

这是一个微信小程序方向的第一版本地原型，目标是先做一个不依赖账号和服务器的私人菜谱工具。

第一版不做账号、云同步、社区、推荐算法和服务器。核心只保留三件事：

- 浏览本地保存的菜谱目录
- 拍照或从相册选择菜品图片
- 编辑菜名、分类、做法等文本内容

## 当前功能

- 首页菜谱目录
- 随机选菜
- 生成一荤一素一汤套餐
- 菜名、食材、备注搜索
- 分类筛选
- 新增菜谱
- 拍照或从相册选图
- 编辑菜名、分类、食材、做法、备注
- 菜谱详情
- 删除菜谱
- 小程序本地保存

## 运行方式

用微信开发者工具打开当前目录：

`C:\Users\Administrator\Documents\New project`

当前使用 `touristappid`，可以先作为游客项目调试。后续如果要真机预览和发布，需要换成你自己的小程序 AppID。

## 项目结构

- `app.js` / `app.json` / `app.wxss`：小程序全局配置和样式
- `pages/index`：菜谱目录页
- `pages/detail`：菜谱详情页
- `pages/edit`：新增/编辑菜谱页
- `utils/storage.js`：本地菜谱存取
- `utils/categories.js`：分类配置
- `utils/format.js`：时间格式化

## 第一版定位

第一版可以理解为：

> 一个只存在用户手机里的私人菜谱本。

它不追求“大而全”，而是验证用户是否愿意把自己做过的菜拍下来、记下来，并能方便地再次找到。

## 重要约束

微信小程序不能像桌面软件一样任意浏览用户手机的所有本地目录。第一版中的“本地目录浏览”建议定义为：

- 用户在小程序里创建和保存的菜谱目录
- 小程序沙盒内保存的图片和文本数据
- 通过系统授权入口选择照片或拍照

如果未来需要更强的本地文件管理能力，可以再评估 App、鸿蒙应用或桌面端。
