# Figma 菜谱 UI 设计规格

目标：把当前小程序首页的原创美术资产和视觉语言同步到 Figma，形成可复用的 UI 设计稿。

## 画板

- 设备：微信小程序移动端首页
- 画板尺寸：`375 x 812`
- 名称：`私人菜谱本 / 首页`
- 背景：暖纸色 `#FBF4E6`，叠加饭粒纹理感

## 视觉基调

- 关键词：私人菜谱、手帐感、温暖、轻游戏化、厨房、木牌、纸张、饭粒、香草
- 参考：`animal-island-ui` 的圆润、纸感、按钮按压感
- 区分：不使用动物岛原始素材，转为菜谱主题原创图形

## 颜色

| Token | Value | 用途 |
| --- | --- | --- |
| `color/bg/page` | `#FBF4E6` | 页面底色 |
| `color/bg/paper` | `#FFFDF7` | 卡片和输入区域 |
| `color/bg/paperWarm` | `#FFF3CF` | 面板和弹层 |
| `color/text/primary` | `#4F351F` | 主标题 |
| `color/text/body` | `#725D42` | 正文 |
| `color/text/muted` | `#9F927D` | 辅助信息 |
| `color/accent/teal` | `#19BBAE` | 筛选选中、次按钮 |
| `color/accent/yellow` | `#FFCC00` | 主按钮 |
| `color/wood` | `#C97932` | 木牌 |
| `color/border/warm` | `#E3C999` | 温暖描边 |

## 字体

- 中文：`PingFang SC` / `Microsoft YaHei` / 系统 sans-serif
- 标题：粗体，接近 `900`
- 正文：`500`
- 按钮：`800-900`

## 组件

1. 品牌木牌
   - 位置：顶部左侧
   - 尺寸：约 `170 x 59`
   - 文案：`私人菜谱本`
   - 装饰：右下角香草芽图标

2. 搜索框
   - 胶囊形
   - 高度：`48`
   - 左侧搜索图标
   - 占位文案：`搜索菜名、食材或备注`

3. 分类胶囊
   - 默认：暖纸底、棕色文字
   - 选中：薄荷青底、白色文字
   - 更多分类区使用纸片面板承载

4. 随机选菜面板
   - 不规则纸卡
   - 标题：`不知道吃什么？`
   - 两个按钮：`随机一道`、`生成菜谱`
   - 按钮使用底部阴影/按压感

5. 菜谱卡片
   - 横向列表卡片
   - 左侧图片框
   - 右侧菜名
   - 图片上叠加分类标签

6. 弹层面板
   - 底部弹出
   - 不规则纸感大面板
   - 用于随机菜、套餐结果

## Figma 同步方式

项目内提供脚本：

`tools/figma-create-cookbook-ui.js`

使用方式：

1. 提供一个 Figma design 文件链接。
2. Codex 通过 Figma `use_figma` 工具执行该脚本。
3. 脚本会创建 `Cookbook UI` 页面，并生成首页画板、色板、关键组件和首页组合稿。
