# 开发准备清单

## 开发环境

需要准备：

- 微信开发者工具
- 小程序测试 AppID，或使用测试号
- 一个空的小程序项目目录
- 基础库版本确认
- 真机调试设备

## 技术路线建议

第一版建议直接使用微信原生小程序。

理由：

- 功能简单，不需要跨端框架
- 拍照、相册、本地文件能力更直接
- 开发者工具调试方便
- 后续如果验证成功，再考虑 UniApp 或 Taro 扩展多端

## 第一版模块拆分

### 页面模块

- 首页列表
- 菜谱详情
- 菜谱编辑

### 能力模块

- 本地菜谱存取
- 图片选择与保存
- 分类筛选
- 搜索过滤
- 删除确认

### UI 组件

- 菜谱卡片
- 图片选择区域
- 分类选择器
- 空状态
- 确认弹窗

## 开发顺序

推荐顺序：

1. 创建小程序项目骨架
2. 做本地数据读写
3. 做首页列表和空状态
4. 做新建/编辑表单
5. 接入拍照和相册选择
6. 做详情页
7. 做分类筛选和搜索
8. 做删除和异常提示
9. 真机测试

## 验收清单

第一版完成时，需要逐项验证：

- 可以新建一道菜
- 可以拍照保存图片
- 可以从相册选择图片
- 可以编辑菜名、分类、食材、做法、备注
- 可以在首页看到已保存菜谱
- 可以搜索菜名
- 可以按分类筛选
- 可以进入详情页查看
- 可以再次编辑并保存
- 可以删除菜谱
- 关闭小程序后重新打开，数据仍然存在
- 没有图片时界面不破
- 没有菜谱时有清楚的空状态

## 暂不处理的技术事项

- 代码分包
- 登录态
- 服务端 API
- 云数据库
- 图片云存储
- 支付能力
- 数据埋点
- 上线审核材料

这些都等第一版本地原型跑通后再处理。
